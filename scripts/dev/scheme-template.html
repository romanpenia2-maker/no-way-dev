Уровень 1 — обзор if-else (без скриншотов)

1. ВХОД

ничего не введено / диплинк ?kind=

  • пусто, 1-й визит → S-EMPTY-FIRST
  • пусто, вернувшийся → S-EMPTY-RETURN
→

2. ГЕЙТЫ ВВОДА (клиент)

submit заблокирован до прохождения

  • text 1–149 слов → S-GATE-SHORT-TEXT
  • text >20 000 слов → S-GATE-LONG-TEXT
  • code 1–39 строк → S-GATE-SHORT-CODE
  • code >50 000 симв. → S-GATE-LONG-CODE
  • img >8 MB → S-IMG-TOO-BIG
  • img не PNG/JPEG/битый → S-IMG-BAD-FORMAT
→

3. IMAGE: C2PA ЛОКАЛЬНО

WASM в браузере, API не вызывается

  • чтение → S-IMG-C2PA-LOADING
  • valid + AI claim → S-IMG-C2PA-AI
  • valid, без AI claim → S-IMG-C2PA-NOAI
  • invalid → S-IMG-C2PA-INVALID → «Check anyway» → п.4
  • нет манифеста / WASM упал → п.4
→

4. СЕРВЕР /api/detect

zeroshot + external + provenance

  • 429 → S-RATE-LIMIT (таймер, вход сохранён)
  • сеть / 5xx → S-NETWORK-ERR (Retry)
  • нет ML и нет ext → S-NO-ML
  • только external → S-EXT-ONLY
  • граничный p + Sapling → S-RES-BORDERLINE-EXT
  • img: нет сигналов → S-IMG-NO-SIGNALS
→

5. ВЕРДИКТ ПО p

все слои ok

  • p ≥ 0.80 → S-RES-CONF-AI
  • 0.55 ≤ p < 0.80 → S-RES-LIKELY-AI
  • 0.20 < p < 0.55 → S-RES-ABSTAIN
  • p ≤ 0.45 симм. → S-RES-LIKELY-HUMAN
  • p ≤ 0.20 → S-RES-CONF-HUMAN
  • правка входа потом → S-RES-STALE-GUARD
